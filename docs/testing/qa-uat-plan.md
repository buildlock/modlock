# QA and user acceptance plan

Status: template  
Last reviewed: 2026-09-01

## Cohorts

- Internal engineering/trust operators on synthetic content.
- Invited creators publishing licensed pilot files.
- Invited players with sacrificial/recoverable Windows installs.
- Accessibility participants or specialist review.

## Scenarios

Creator account→draft→upload→finding→fix→approve→publish; public discovery/source/license; one-click and manual install; cancellation/interruption/rollback; update and patch repair; profiles/conflicts/variants; CFG diff/restore; crosshair explicit activation; pack partially unavailable/revoked; offline library; report/moderation/appeal; account export/deletion.

## Entry

Release gates, rights, staging isolation, support/on-call, rollback, revocation, policies/consent, diagnostics/privacy, known issue list, and recovery/reinstall support are ready.

## Exit

No open critical/high security or unrecoverable mutation issue; reliability/performance/accessibility targets pass or have approved limited scope; every pilot artifact has rights; support cases have reproducible outcomes; users understand source/verification/compatibility/install plan in moderated testing.

UAT feedback is evidence, not permission to override safety boundaries. Record consent, environment, task result, confusion/error, severity, and mapped feature/test issue without collecting unnecessary gameplay/personal data.
