# Creator publishing guide

Status: pre-release draft  
Last reviewed: 2026-09-01

## Prepare

- Confirm you own or can distribute every asset; identify third-party sources/terms.
- Choose one immutable release version and clear variants.
- Package only the necessary supported mod content; no executables, loaders, drivers, injected DLLs, or hidden installers.
- Provide accurate title/description/category/heroes/content rating/capabilities, tested game build, changelog, license, attribution, dependencies/conflicts, and optional creator-owned donation link.

## Publish

Create a draft, upload directly to quarantine, review the generated inventory and scan findings, correct metadata/package issues, submit for policy review when required, and verify the final public release. Published bytes are not replaced; make a new version.

## Updates/removal

Deprecate old compatible releases rather than rewriting them. Security/policy/copyright risk can revoke new installs while preserving case evidence. Contact support for ownership changes, co-authors, disputes, or takedown/appeal.

GameBanana-linked content remains hosted there and retains its source/license/donation page. Modlock never treats a public download link as redistribution permission.
