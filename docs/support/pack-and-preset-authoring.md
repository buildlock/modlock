# Pack, CFG preset, and crosshair authoring guide

Status: pre-release draft  
Last reviewed: 2026-09-01

## Packs

Reference exact authorized source/release/file/variant versions; mark required/optional; choose deterministic priority; document conflicts, game build, and purpose. Packs contain no third-party binary payloads. A version never silently tracks latest; publish a new pack version to update.

## CFG presets

Use only supported typed registry keys. Explain each value/risk and tested game build. Do not upload whole `video.txt`, `gameinfo.gi`, hardware identifiers, unknown commands, visibility/outline/fog advantages, input automation, or arbitrary scripts. Users see a diff before application.

## Crosshairs

Provide exact structured values, preview disclaimer, tested build, and hero tags/preferences. Per-hero tagging does not promise automatic in-match switching.

## Verification

Player/streamer identity and approval of one exact version are separate. Community-reported artifacts cite public sources and cannot imply endorsement. New values/items or expiration require reapproval.
