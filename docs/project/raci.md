# Workstream RACI

Status: initial small-team model  
Last reviewed: 2026-09-01

`A` accountable, `R` responsible, `C` consulted, `I` informed. One named human may temporarily hold multiple roles, but production privileges remain separated technically where required.

| Workstream | Product/operator | Platform | Desktop | Security/trust | Design/UX | Counsel | Creators/testers |
|---|---|---|---|---|---|---|---|
| Scope/roadmap | A/R | C | C | C | C | I | C |
| Contracts/data model | A | R | R | C | C | I | I |
| Catalog/upload/API | A | R | C | C | C | I | C |
| Scanner/moderation | A | R | C | R | C | C | C |
| Desktop installer/updater | A | C | R | C | C | I | C |
| CFG/crosshair/packs | A | C | R | C | R | I | C |
| Identity/verification | A | R | C | R | C | C | C |
| Policies/takedowns/privacy | A | C | I | R | I | C/R approval | I |
| Infrastructure/operations | A | R | C | C | I | I | I |
| Release go/no-go | A | R evidence | R evidence | R evidence | C | C | I |

Before beta, replace role labels with named primary/backup owners and escalation contacts.
