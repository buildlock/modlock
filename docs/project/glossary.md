# Glossary

| Term | Definition |
|---|---|
| Artifact approval | Evidence that an identity approved one exact immutable release/preset/pack version. |
| Blob | Exact stored bytes identified by SHA-256. |
| Capability | Conservatively inferred effect class such as cosmetic VPK, audio replacement, CFG setting, or executable payload. |
| Clean-room evidence | Behavioral/interoperability requirement recorded without copying incompatible implementation code. |
| Compatibility | Evidence relationship between an exact artifact version and game build; `unknown` is distinct from incompatible. |
| Creator verification | Evidence that an account controls an attributable public creator/player identity. |
| External-linked | Metadata/reference whose bytes remain on an authorized third-party host. |
| Fixture | Synthetic or licensed input plus rights and expected outcome used for tests. |
| Install plan | Signed, expiring, exact set of source files/hashes/risks/priority resolved for desktop confirmation. |
| Journal | Durable write-ahead record enabling install recovery/rollback. |
| Modlock-hosted | Creator-authorized file stored in Modlock quarantine/public storage after scanning/policy approval. |
| Object store | Local desktop immutable content-addressed cache or server blob storage, depending on context. |
| Owned block | Delimited configuration section Modlock may deterministically replace without modifying unrelated user content. |
| Pack | Immutable manifest referencing authorized exact mod files/variants/priorities; never a rebundled third-party ZIP. |
| Profile | Local desired state of enabled versions/variants/load order and selected settings. |
| Provenance | Creator, source, license, remote identity, hash, observation, and approval evidence explaining origin/rights. |
| Quarantine | Non-public upload storage/processing zone with no path to public access except authorized promotion. |
| Resolution receipt | Local/server record of the exact install plan presented and outcome. |
| Revoked | New resolution/activation blocked for policy/security/legal reason while evidence/history remains. |
| Scan attestation | Versioned scanner result bound to exact blob digest; not a guarantee of safety. |
| Source adapter | Provider-specific normalized discovery/file resolver with schema/caching/failure boundaries. |
| VPK | Valve package format used by Source/Source 2 content; may include `_dir.vpk` and numbered parts. |
